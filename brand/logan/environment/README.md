# Portrait environment

`studio_small_09_2k.hdr` is **Studio Small 09** by Sergej Majboroda, from
[Poly Haven](https://polyhaven.com/a/studio_small_09), released under
[CC0](https://polyhaven.com/license). It provides unclipped studio reflections.

`server-room-neutral.png` is the current background, generated with `gpt-image-2.5`
through the image-gen skill. Its brief: out-of-focus graphite server racks at
the edges, broad soft white practical lights, and a quiet smoky grey center.
The restrained palette supports both screen polarities on pink Logan. Soft focus keeps
the robot legible at avatar size. Both portraits use the same plate.
It is an ordinary image, not an HDR lighting map. The camera-only plane keeps
its painted lights separate from the actual HDRI and portrait lights. The plate
and HDRI are packed into the studio.

`command-room.png` and its blue/pink derivatives are retained source studies
for a defocused server-room treatment. `soften-background.py` regenerates those
derivatives; the current portrait does not use them.

`arcade-playground.png` is a retained study of oversized tangerine and mint
sculptural forms against plum.
