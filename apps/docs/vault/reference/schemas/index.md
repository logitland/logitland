---
title: Schemas
description: The objects the relay returns, as `@logitland/contracts` defines them.
order: 3
---

Endpoint and tool pages link these where a response carries one of them. Each is written from its
[contract](https://github.com/logitland/logitland/blob/main/packages/contracts/src/schemas.ts), so the fields, types,
patterns and allowed values here are the ones the relay checks.
