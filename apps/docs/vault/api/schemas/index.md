---
title: Schemas
description: 'The objects the relay returns, as `@logitland/contracts` defines them.'
order: 11
---

Endpoint and tool pages link these wherever a response carries one. Each is written from its
[contract](https://github.com/logitland/logitland/blob/main/packages/contracts/src/schemas.ts), so its fields, types,
patterns, and allowed values are the ones the relay checks.
