# Design canvas

Source of the "Flock & Cord" design canvas artifact: 15 artboards (`*.dc.html`) and their layout (`canvas.json`), with research notes as stickies.
"Flock & Cord" is the artifact's historical name, not the current product name.
The [clickable prototype](../../apps/prototype/README.md) is in `apps/prototype`; the production app is in `apps/web`.

The boards use the canvas runtime's template syntax (`{{holes}}`, `<sc-for>`, `<sc-if>`, a `DCLogic` class), so they render only inside that artifact type.
