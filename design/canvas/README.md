# Design canvas

Source of the "Flock & Cord" design canvas artifact: 15 artboards (`*.dc.html`) and their layout (`canvas.json`), with research notes as stickies. The clickable version is `apps/prototype`; the production app is `apps/frontend`.

The boards use the canvas runtime's template syntax (`{{holes}}`, `<sc-for>`, `<sc-if>`, a `DCLogic` class), so they render only inside that artifact type.
